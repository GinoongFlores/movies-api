Movies API

The main browser demo is the React app. This server is the JSON API on port 5000.

Open the React demo

  1. Keep this API running: python app.py (port 5000).
  2. In another terminal: cd frontend, then npm install, then npm run dev.
  3. Open http://127.0.0.1:5173.

React runs on port 5173. Flask stays on port 5000. Those are different origins, so the browser uses CORS. flask-cors in app.py allows the React page to call /movies.

Compare with the vanilla HTML/JS twin. Same /movies routes. One HTML file and one script, instead of components.

curl to /movies still returns JSON. This HTML is only what a browser gets for GET /.
